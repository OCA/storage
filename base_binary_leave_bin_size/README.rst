This module is a base technical module in order to optimize the
rendering of images in two steps. One for computing - synchronous - (for
which is not necessary to retrieve the size) and one - asynchronous -
for web rendering.

**Table of contents**

.. contents::
   :local:

Use Cases / Context
===================

- In installs where storage is not a disk, calling the distant url to
  retrieve the bin size could be bulky. So, force the bin size except
  when loading the image for web rendering.
